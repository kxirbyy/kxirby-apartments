## Kxirby Apartments - Basic Alta Street Housing

Hey, this is my second release and I wanted to keep things simple. This is a lightweight apartment script for Alta Street that gives each player their own private space using routing buckets.

I built this to be super basic on purpose. It's not trying to be some crazy advanced system. Just a functional apartment that works. You get a private instance, a stash for storage (50 slots), and a clothing menu inside. That's it.

The code is intentionally clean and easy to read. If you want to fork it and add your own features, go ahead. I made everything editable so you can expand on it however you want. Add more apartment locations, change the interior, add furniture systems, whatever. The foundation is there for you to build on.

Dependencies:
ESX Legacy
ox_lib
ox_inventory
illenium-appearance

I added optimized distance checks so it won't tank your server performance and there's auto cleanup when the script restarts so nobody gets stuck inside.

This isn't meant to be some out of the water asset. It's a starting point. I'm planning to release a free version for anyone who wants a basic apartment system without all the bloat.

If you improve it or add cool features feel free to share. That's why I kept the code simple so others can learn from it or make it better.
